# Korean Drama Machine Learning Project 🎬

A practice project focused on data cleaning, exploratory data analysis (EDA), and machine learning modeling using a Korean Drama dataset. 

## 🎯 Project Goal
To explore the dataset, clean and preprocess the data, and build a personalized recommendation system for K-dramas.

---

## 🛠️ Tech Stack
* **Python**
* **Pandas / NumPy** (Data Manipulation & Cleaning)
* **Scikit-Learn** (Modeling & Recommendation)
